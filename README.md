# QuickNotes App

QuickNotes is a simple and responsive web application that allows users to create, organize, search, and delete personal notes. Each note can be assigned to a category, and notes are stored in the browser using localStorage so they remain available even after refreshing the page.

## Features

* Add new notes
* Delete notes
* Search notes
* Categorize notes as Personal, Work, or School
* Validate notes before saving
* Limit notes to 200 characters
* Display the number of notes
* Save notes using localStorage
* Load saved notes after refreshing the page
* Responsive design for mobile devices
* Different visual styles for each note category

## How to Run the Project Locally

1. Clone the repository:

```bash
git clone https://github.com/bngraphics254-ops/quicknotes-app.git
```

2. Enter the project directory:

```bash
cd quicknotes-app
```

3. Open `index.html` in your web browser.

No additional software, packages, or dependencies are required.
